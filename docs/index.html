Store screenshots, rendered from your code

A Claude Code skill. Claude reads your app, writes the captions in every language you ship, and renders App Store and Google Play images at exact store sizes. It also renders app preview videos and the product page header, search and In-App Event assets. Free, local and open source.

Install

Claude Code plugin

/plugin marketplace add dtthaison/app-screenshots-pro-skill
/plugin install app-screenshots-pro-skill@app-screenshots-pro-skill

Then ask: “Make App Store and Play screenshots for this app in English and German.”

Run the renderer yourself

git clone https://github.com/dtthaison/app-screenshots-pro-skill.git
cd app-screenshots-pro-skill/skills/generating-app-screenshots
npm install
node scripts/render.mjs path/to/screenshots.config.json

Needs Node.js 18.17+ and Chrome or Edge. Full documentation
